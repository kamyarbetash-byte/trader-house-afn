# راهنمای راه‌اندازی رهبر پی (Rahbar Pay)

این راهنما مراحل اجرای پروژه روی کمپیوتر شما و انتشار آن روی Cloudflare را قدم‌به‌قدم توضیح می‌دهد.

> ⚠️ این نسخه **نمایشی** است. هیچ پرداخت واقعی انجام نمی‌شود. تا زمانی که مجوز قانونی و قرارداد با ارائه‌دهندگان (اتوما پی، حساب پی، بانک) را نگرفته‌اید، حساب پرداخت واقعی وصل نکنید و خدمات رمزارز را فعال نکنید.

## ۱. پیش‌نیازها
- Node.js نسخه ۲۰ یا جدیدتر
- یک حساب رایگان Cloudflare

## ۲. اجرا روی کمپیوتر خودتان

دستورهای زیر را در ترمینال بنویسید:

```bash
cd rahbar-pay
npm install
npx wrangler d1 migrations apply rahbar-pay --local
echo 'ADMIN_SETUP_KEY=یک-کلید-طولانی-و-تصادفی' > .dev.vars
npm run dev
```

سپس آدرس `http://localhost:8787` را در مرورگر باز کنید.

- **ساخت حساب مشتری:** به صفحه `/register` بروید. در حالت نمایشی، کد تأیید روی صفحه نشان داده می‌شود (پیامک ارسال نمی‌شود).
- **ساخت نخستین مدیر:** صفحه `/admin/setup` را باز کنید و کلید ADMIN_SETUP_KEY را وارد کنید.
- **ورود مدیر:** از صفحه `/admin` وارد شوید. کلید محرمانه نمایش‌داده‌شده را در برنامه Google Authenticator یا Microsoft Authenticator اضافه کنید و کد ۶ رقمی آن را وارد کنید.

## ۳. انتشار روی Cloudflare (Workers + D1)

```bash
cd rahbar-pay
npx wrangler login
npx wrangler d1 create rahbar-pay
```

دستور آخر یک `database_id` نشان می‌دهد. آن را در فایل `wrangler.toml` به‌جای صفرها بگذارید، و بعد ادامه دهید:

```bash
npx wrangler d1 migrations apply rahbar-pay --remote
npx wrangler secret put ADMIN_SETUP_KEY
npm run deploy
```

پس از انتشار، فقط یک بار آدرس `https://rahbar-pay.<زیردامنه‌شما>.workers.dev/admin/setup` را باز کنید و مدیر اول را بسازید.

- **دامنه اختصاصی:** در `wrangler.toml` این خط را اضافه کنید:

  ```toml
  routes = [{ pattern = "pay.example.com", custom_domain = true }]
  ```

- **انتشار خودکار از GitHub:** در داشبورد Cloudflare یک پروژه Workers Builds بسازید و **Root directory** را `rahbar-pay` بگذارید. سایت فعلی nirkh.com در ریشه مخزن جداگانه است و تغییری نمی‌کند.

## ۴. بخش‌های اختیاری

### ذخیره رسیدها در R2

```bash
npx wrangler r2 bucket create rahbar-pay-files
```

سپس بخش `[[r2_buckets]]` را در `wrangler.toml` از حالت توضیح بیرون بیاورید.

### اعلان تلگرام

۱. با @BotFather یک ربات بسازید.

۲. توکن ربات و یک رمز تصادفی برای وب‌هوک را ثبت کنید:

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put TELEGRAM_WEBHOOK_SECRET
```

۳. وب‌هوک را تنظیم کنید. به‌جای `<TOKEN>` توکن ربات و به‌جای `<SECRET>` همان رمز وب‌هوک را بگذارید:

```bash
curl "https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<دامنه>/api/telegram/webhook&secret_token=<SECRET>"
```

۴. نام کاربری ربات را در **مدیریت ← تنظیمات سیستم ← عمومی** وارد کنید.

پیام‌های تلگرام فقط وضعیت را نشان می‌دهند و هرگز مبلغ، نام یا مشخصات حساب را شامل نمی‌شوند.

## ۵. روش‌های پرداخت
- **اتوما پی (ATOMA Pay):** تأیید دستی
- **حساب پی (Hesap Pay):** تأیید دستی
- **انتقال بانکی:** تأیید دستی، فقط به حساب شرکت
- **درگاه کارت مجاز:** غیرفعال، تا زمانی که یک درگاه مجاز وصل شود

## ۶. قانون مهم تأیید پرداخت

سیستم اجازه نمی‌دهد درخواستی فقط با اسکرین‌شات مشتری به وضعیت «پرداخت تأیید شد» برود.

کارمند باید یک «ثبت تأیید» انجام دهد که منبع آن یکی از این‌ها باشد:
- API ارائه‌دهنده
- سابقه تأییدشده تراکنش بانکی
- صورت‌حساب رسمی که به‌طور مستقل بررسی شده است

علاوه بر این:
- مبلغ تأییدشده باید با مبلغ درخواست برابر باشد.
- هر شماره مرجع فقط یک بار قابل تأیید است.
- هر اقدام با شناسه کارمند و زمان در «ثبت فعالیت‌ها» ذخیره می‌شود.

## ۷. پیش از راه‌اندازی واقعی
۱. مجوز قانونی بگیرید و با ارائه‌دهندگان پرداخت قرارداد امضا کنید.

۲. یک سرویس پیامک را در تابع `issueOtp` وصل کنید و سپس `DEMO_MODE` را `"false"` بگذارید.

۳. مشخصات حساب بانکی **شرکت** را در رهنمود هر روش پرداخت بنویسید (هرگز حساب شخصی).

۴. پیش از استفاده مشتریان واقعی، بررسی امنیتی انجام دهید.
